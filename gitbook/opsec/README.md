# OPSEC — Risques opérationnels

Référentiel de visibilité et de traçabilité des opérations de laboratoire.

- **SAFE** : activité considérée peu intrusive dans le contexte documenté.
- **CAUTION** : activité nécessitant une vérification du périmètre et des effets.
- **UNSAFE** : activité présentant des risques élevés de perturbation ou de détection.

Ces étiquettes ne garantissent jamais l'absence de détection.
