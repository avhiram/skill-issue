Repères OPSEC ​

🔴 UNSAFE
🟠 CAUTION
🟢 SAFE

  • Les opérations Red Team doivent rester undetected et éviter de déclencher des alertes de sécurité.
  • Privilégier des techniques stealthy qui se fondent dans l’activité normale du système.
  • Exploiter les processus légitimes et les outils natifs avec une approche Living off the Land (LotL).
  • Réutiliser les credentials, tokens et tickets pour effectuer une impersonation sans connaître les mots de passe.
  • Imiter l’activité normale afin de limiter les détections par l’antivirus.
  • Contourner les protections endpoint sans déclencher d’alertes.

Préparation à l’examen CRTO — Labs ​

  1. Installer et préparer Cobalt Strike
    Lab — Préparation de Cobalt Strike 🕒 30 min | Poste Attacker | Utilisateur : Attacker

  2. Configurer le Malleable C2 Profile, préparer les payloads et contrôler les binaires avec ThreatCheck.
    Lab — Évasion des défenses 🕒 45 min | Attacker, DC, Poste Windows, Serveur web | Utilisateur : pchilds

  3. Énumérer les politiques AppLocker, UAC et antivirus du poste avec les credentials fournis.
    Challenge AppLocker 🕒 45 min | Attacker, DC, Poste Windows | Utilisateur : pchilds

  4. Obtenir un Beacon SYSTEM depuis le premier poste en utilisant l’accès privilégié.
    Lab — Accès initial 🕒 45 min | Attacker, DC, Poste Windows | Utilisateur : pchilds

  5. Réaliser une user impersonation depuis un Beacon SYSTEM sur la workstation.
    Lab — Usurpation d’identité 🕒 30 min | Attacker, DC, Poste Windows, Serveur web | Utilisateurs : pchilds, rsteel

  6. Effectuer un jump avec l’identité de l’utilisateur et lancer un Beacon sur la cible suivante.
    Lab — Lateral Movement 🕒 30 min | Attacker, DC, Poste Windows, Serveur web | Utilisateurs : pchilds, rsteel

  7. Utiliser S4U sur un serveur pour effectuer une admin impersonation.
    Lab — Kerberos Constrained Delegation 🕒 30 min | Attacker, Poste Windows, DC, Serveur web, Serveur de fichiers | Utilisateur : pchilds

  8. Utiliser les permissions du SQL DB owner pour effectuer une impersonation avec un payload.
    Lab — SQL Server 🕒 45 min (Attacker, Poste Windows, DC, SQL 1, SQL 2 | Utilisateurs : pchilds, rsteel

  9. Exploiter SeImpersonatePrivilege sur le serveur et se connecter à localhost.
    Lab — SQL Server 🕒 45 min (Attacker, Poste Windows, DC, SQL 1, SQL 2 | Utilisateurs : pchilds, rsteel

  10. Utiliser une Parent-Child Trust et un Golden Ticket pour effectuer une impersonation et créer un Beacon.
    Lab — Relation de confiance parent-enfant 🕒 30 min | Attacker, Dublin Poste Windows, Contoso DC, Dublin DC | Utilisateur : DUBLIN\sguest

  11. Mettre en place un DNS Beacon sur le Domain Controller pour renforcer la résilience.
    Lab — Persistence élevée 🕒 30 min | Attacker, DC, Poste Windows | Utilisateur : pchilds

  12. Utiliser la clé d’une inter-realm trust et un Golden Ticket pour lancer un Beacon avec impersonation.
    Lab — Trust entrante 🕒 30 min | Attacker, Contoso Poste Windows, Partner Jump Server, Contoso DC, Partner DC | Utilisateur : PARTNER\vwebber

  13. Effectuer la phase Active Directory Discovery.
    Lab — Discovery Active Directory 🕒 30 min | Attacker, DC, Poste Windows | Utilisateurs : pchilds, rsteel

  14. Utiliser S4U Constrained Delegation et l’attribut Allowed To Delegate To.
    Lab — Kerberos Constrained Delegation 🕒 30 min | Attacker, Poste Windows, DC, Serveur web, Serveur de fichiers | Utilisateur : pchilds

  15. Configurer un SOCKS proxy pour réaliser du pivoting vers d’autres sous-réseaux.
    Lab — Pivoting SOCKS 🕒 30 min | Attacker, Poste Windows, DC | Utilisateurs : pchilds, rsteel

  16. Étudier RBCD et la propriété Allowed To Act On Behalf Of Other Identity.
    Lab — Kerberos RBCD 🕒 30 min | Attacker, Poste Windows, DC, Serveur de fichiers | Utilisateur : pchilds

  17. Étudier la Kerberos Constrained Delegation, la Service Name Substitution et l’option S4U /altservice.
    Lab — Kerberos Service Name Substitution 🕒 30 min | Attacker, Poste Windows, DC, Serveur de fichiers, Serveur web | Utilisateurs : pchilds,rsteel

  18. Étudier S4U2self et la récupération d’un TGT. Kerberos S4U2self 🕒 30 min | Attacker, Poste Windows, DC, Serveur web | Utilisateurs : pchilds,rsteel

  19. Identifier une mauvaise configuration Kerberos, puis effectuer un Lateral Movement vers le Domain Controller.
    Challenge Kerberos 🕒 60 min 🖥️ Attacker, LON-WKSTN-1, LON-DC-1 | Utilisateurs : pchilds, Administrator, Compte machine 3e7
