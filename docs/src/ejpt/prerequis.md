# Prérequis

Comprendre l'environnement de travail avant de commencer les tests.

## Objectifs

- Identifier les systèmes Linux et Windows.
- Comprendre les adresses IP, les ports, les protocoles et les routes.
- Comprendre une requête HTTP et une réponse.
