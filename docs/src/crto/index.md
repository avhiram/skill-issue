# CRTO

**Certified Red Team Operator**

Cet espace accueillera progressivement les notes CRTO, classées par technologie et par technique.

Chaque fiche suivra un format simple : **titre précis, explication courte, bloc de commande copiable et remarques utiles**.

Aucune fiche n'est présentée comme complète tant que son contenu technique n'est pas réellement intégré.
