# Lateral Movement

> Après la phase de **Discovery**, une fois les groupes de l’utilisateur courant et ses privilèges d’administrateur local identifiés, la phase de **Lateral Movement** permet d’accéder à d’autres machines du réseau.

* Windows Remote Management (**WinRM**)
* **PsExec**
* Techniques personnalisées
* Outils **LOLBAS**
* Types de sessions **Security Logon**
