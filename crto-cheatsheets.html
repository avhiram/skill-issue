LDAP — Énumération Active Directory

Énumération des comptes utilisateurs

ldapsearch (samAccountType=805306368) --attributes samaccountname,memberof,admincount

Liste les utilisateurs et leurs groupes.

Énumération des comptes ordinateurs

ldapsearch (samAccountType=805306369) --attributes dnshostname,operatingsystem

Liste les machines et leurs systèmes.

Énumération des groupes AD

ldapsearch (samAccountType=268435456) --attributes samaccountname,member

Liste les groupes et leurs membres.

Identification des comptes privilégiés

ldapsearch (&(samAccountType=805306368)(adminCount=1)) --attributes samaccountname,memberof

Recherche les comptes protégés par AdminSDHolder.

Inventaire des unités organisationnelles

ldapsearch (objectClass=organizationalUnit) --attributes name,distinguishedName

Affiche la structure des OU.

Inventaire des GPO

ldapsearch (objectClass=groupPolicyContainer) --attributes displayName,gPCFileSysPath

Identifie les stratégies de groupe.

Cartographie des relations d'approbation

ldapsearch (objectClass=trustedDomain) --attributes trustPartner,trustDirection,trustAttributes

Liste les trusts Active Directory.

Audit des filtres WMI associés aux GPO

ldapsearch (objectClass=msWMI-Som) --attributes msWMI-Name,msWMI-Parm2

Identifie les filtres WMI existants.

Vérification du filtrage WMI des GPO

ldapsearch (objectClass=groupPolicyContainer) --attributes displayname,gpcwqlfilter

Vérifie les GPO avec filtre WMI.

BloodHound — Cartographie AD

Conversion des journaux LDAP avec BOFHound

bofhound -i logs

Produit des fichiers JSON pour BloodHound.

Inventaire des GPO dans BloodHound

MATCH (n:GPO) RETURN n

Affiche les objets GPO.

Inventaire des machines dans BloodHound

MATCH (n:Computer) RETURN n

Affiche les ordinateurs importés.

Inventaire des groupes dans BloodHound

MATCH (n:Group) RETURN n

Affiche les groupes importés.

Visualisation des relations entre domaines

MATCH (n:Domain) RETURN n

Affiche les domaines présents.

Windows — Contrôles AppLocker

Vérification du mode d'exécution PowerShell

$ExecutionContext.SessionState.LanguageMode

Identifie FullLanguage ou ConstrainedLanguage.

Lecture de la politique AppLocker effective

Get-AppLockerPolicy -Effective | Select-Object -ExpandProperty RuleCollections

Affiche les collections de règles actives.

Analyse détaillée des règles AppLocker

$policy = Get-AppLockerPolicy -Effective
$policy.RuleCollections | Format-List *

Affiche les paramètres des règles.

Inspection des règles de contrôle DLL

$policy.RuleCollections | Where-Object { $_.RuleCollectionType -eq 'Dll' }

Vérifie la présence de règles DLL.

Lecture des règles AppLocker dans le registre

Get-ChildItem 'HKLM:Software\Policies\Microsoft\Windows\SrpV2'

Liste les catégories de règles configurées.

Contrôle des ACL d'un répertoire Windows

icacls C:\Windows\Tasks

Affiche les droits du dossier.

Contrôle des ACL du dossier temporaire

icacls C:\Windows\Temp

Affiche les droits du dossier.

Contrôle des ACL du dossier Tracing

icacls C:\Windows\Tracing

Affiche les droits du dossier.
