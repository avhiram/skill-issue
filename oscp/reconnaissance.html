Netcat ​

Netcat : tester un port TCP, envoyer des datagrammes UDP ou ouvrir une écoute locale selon la commande.

bash
nc -nv 192.0.2.10 80

# Envoyer des datagrammes UDP (aucune réponse ne garantit pas que le port est fermé)
nc -u -nv 192.0.2.10 53

# Écouter les connexions TCP entrantes sur le port local 4444
nc -l 4444

# Rester en écoute après une déconnexion (option -k selon la variante de Netcat)
nc -k -l 4444

# Tester les ports TCP 1 à 1024 avec un délai maximal d'une seconde
nc -nvv -w 1 -z 192.0.2.10 1-1024

# Balayer une plage de ports UDP : -w fixe le délai, -z évite les échanges applicatifs ; résultat UDP incertain
nc -nvu -z -w 1 192.0.2.10 53-55

# Vérifier un port UDP précis ; l'absence de réponse ne confirme pas son ouverture
nc -nvzu -w 2 192.0.2.10 53

# Écouter sur un port TCP local (aucun shell n'est créé par cette commande seule)
nc -nvlp 4444

Script Python : implémentation de «SMTP».

python
import socket
import sys

if len(sys.argv) != 3:
    print("Utilisation : python3 vrfy.py <utilisateur> <ip_cible>")
    sys.exit(1)

# Créer une socket
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# Se connecter au serveur
ip = sys.argv[2]
s.settimeout(10)
s.connect((ip, 25))

# Recevoir la bannière
banner = s.recv(1024)
print(banner)

# Envoyer une requête SMTP VRFY pour l'utilisateur indiqué
user = (sys.argv[1]).encode()
s.send(b'VRFY ' + user + b'\r\n')
result = s.recv(1024)
print(result)

# Fermer la socket
s.close()

Découverte via un proxy TCP ​

Utiliser un scan TCP connect lorsque l'accès réseau passe par un proxy SOCKS. Les scans SYN ou UDP ne se comportent pas comme un scan TCP connect derrière proxychains.

Découverte via un proxy TCP.

bash
proxychains4 -q nmap -sT -Pn --top-ports 200 <IP_CIBLE>
