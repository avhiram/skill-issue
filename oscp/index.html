OSCP ​

Offensive Security Certified Professional

Fiches par technique avec des explications courtes et les commandes originales dans des blocs copiables.

Sommaire ​

  • Reconnaissance : Identifier les hôtes, les ports et les services accessibles.
  • Analyse de vulnérabilités : Évaluer les services exposés et rechercher des faiblesses connues.
  • Applications web : Examiner les fonctionnalités, entrées et configurations des applications web.
  • Attaques côté client : Comprendre les vecteurs d'interaction avec les postes utilisateurs.
  • Antivirus et Metasploit : Références sur les protections, charges utiles et outils de laboratoire.
  • Mots de passe et authentification : Analyser les mécanismes d'authentification et les formats de hachage.
  • Élévation de privilèges Windows : Auditer les services, jetons et configurations d'un poste Windows.
  • Élévation de privilèges Linux : Examiner les permissions, processus et configurations d'un système Linux.
  • Redirection de ports : Documenter les redirections locales, distantes et dynamiques.
  • Tunneling : Référence des outils de tunnel et des modes de transport réseau.
  • Active Directory : fondamentaux : Comprendre les objets, protocoles et mécanismes d'un domaine.
  • Active Directory : énumération : Identifier les utilisateurs, groupes, services et relations du domaine.
  • Active Directory : techniques : Étudier les mécanismes d'authentification et les techniques AD.
  • Active Directory : mouvement latéral : Référence des accès distants et protocoles entre hôtes Windows.
  • Infrastructures cloud : Repères sur l'évaluation des environnements cloud.
  • Rapports de pentest : Documenter les constats et les preuves techniques.
  • Transfert de fichiers : Envoyer, récupérer et encoder des fichiers dans un laboratoire.
  • Utilitaires : Commandes courantes et outils complémentaires.
  • Méthodologie OSCP : Organiser les vérifications et la collecte des résultats.

Les commandes sont présentées telles qu'elles figurent dans la source, avec ses paramètres et ses exemples de laboratoire.

Les commentaires intégrés aux commandes restent dans leur langue d'origine pour éviter d'altérer leur syntaxe.

Source : Emmanuel Solis, OSCP+ Cheatsheet.
