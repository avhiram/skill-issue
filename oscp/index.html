Offensive Security Certified Professional

Liham · OffSec · Vérifier le certificat

Pendant l’examen, OffSec interdit notamment Nessus et SQLmap. Règles officielles de l’OSCP+.

Toutes les rubriques ​

  • Collecte d’informations : Identifier les hôtes, les services et les informations accessibles.
  • Analyse de vulnérabilités : Examiner les services et leurs vulnérabilités connues.
  • Applications web : Retrouver les outils et les vérifications des applications web.
  • Attaques côté client : Consulter les techniques côté poste client.
  • Évasion antivirus et Metasploit : Consulter les références relatives aux antivirus et à Metasploit.
  • Attaques par mots de passe : Identifier les outils et les formats liés à l’authentification.
  • Élévation de privilèges Windows : Vérifier les configurations et privilèges sous Windows.
  • Élévation de privilèges Linux : Vérifier les permissions et configurations sous Linux.
  • Redirections SSH, Socat et netsh : Comprendre où ouvrir les ports et comment tester chaque relais.
  • Ligolo-ng, Chisel et pivot : Reproduire un tunnel simple, un double pivot et des listeners.
  • Théorie Active Directory : Comprendre les objets, tickets et droits Active Directory.
  • Énumération Active Directory : Examiner les comptes, groupes et services du domaine.
  • Attaques Active Directory : Retrouver les techniques de sécurité offensive Active Directory.
  • Mouvement latéral Active Directory : Consulter les protocoles et les accès distants Windows.
  • Infrastructures cloud : Contrôler les accès S3 dans un laboratoire autorisé.
  • Rédaction de rapports : Préparer les preuves, captures et rapports d’audit.
  • Transferts Linux et Windows : Choisir les commandes par sens de transfert et machine.
  • Utilitaires : Consulter les commandes et outils complémentaires.
  • Méthodologie : Organiser les vérifications pendant un examen.
  • Références : Consulter les consignes officielles de l’examen.
