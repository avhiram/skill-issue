# Procédure permanente d'import des dépôts de cours

1. Identifier le dépôt, sa licence et les parcours demandés.
2. Figer la révision Git et inventorier chaque fichier, y compris les ressources et les images.
3. Télécharger l'archive complète, vérifier chaque empreinte Git et conserver les originaux intacts.
4. Mettre à disposition une première version fidèle, sans inventer ni supprimer de texte, de commandes, d'images ou de chapitres. Séparer le rendu HTML de l'archive originale.
5. Contrôler le nombre de fichiers, les pages, les liens, les médias et le déploiement.
6. Seulement après validation de l'import, travailler par lots sur la traduction, la structure, les titres et la présentation SKILL-ISSUE.
7. Conserver les attributions, licences et mentions de droits obligatoires. Ne pas remplacer un contenu absent par un contenu inventé. Ne pas modifier le code source original.

La répartition gratuit/membre des nouveaux parcours est choisie par le propriétaire du site.
