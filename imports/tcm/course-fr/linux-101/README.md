# Linux 101

![Linux 101 - academy.tcm-sec.com - © TCM Security](.gitbook/assets/linux101.png)

## Objectifs du cours [Linux101](https://academy.tcm-sec.com/p/linux-101)

* Acquérir les bases de Linux, sans expérience préalable.
* Apprendre à utiliser la ligne de commande de manière pratique.
