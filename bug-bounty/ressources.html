Browser Extensions ​

Extensions classées par usage. Les liens Chrome proviennent du document Best Browser Extensions for Bug Hunting and Cybersecurity, mis à jour le 23 avril 2026. Les liens Firefox et GitHub sont conservés. La disponibilité, la compatibilité et l'identité des éditeurs n'ont pas été vérifiées individuellement. Examiner les permissions et utiliser un profil de navigateur dédié aux tests ; éviter d'accorder l'accès à des sessions ou à des données sensibles. Les extensions similaires mais distinctes restent séparées.

Reconnaissance et OSINT ​

  • Wappalyzer - Identification des technologies Web. Firefox · Chrome
  • Hunter.io - Recherche d'adresses e-mail professionnelles. Firefox · Chrome
  • Link Gopher - Extraction des liens. Firefox · Chrome
  • WaybackURLs - Consultation des URL archivées. Firefox
  • Shodan - Informations publiques sur les services Internet. Firefox · Chrome
  • EXIF Viewer Pro - Lecture des métadonnées EXIF des images. Chrome
  • Wayback Machine - Extension de l'Internet Archive pour consulter les versions archivées. Chrome
  • YesWeHack VDP Finder - Identifie les programmes de divulgation de vulnérabilités associés aux sites visités. Chrome
  • Mitaka - Recherche d'indicateurs IP, domaines, URL et hashes dans des services de renseignement. Chrome
  • Vortimo - Organisation des observations OSINT et captures de pages. Chrome
  • IP Address and Domain Information - Consultation des informations IP, ASN, WHOIS et hébergement. Chrome

  • FindSomething - Inspection des références et paramètres. Firefox · Chrome
